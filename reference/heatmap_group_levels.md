# Canonical heatmap group order

Diatoms, Dinoflagellates, Cyanobacteria, Cryptophytes, Ciliates,
Silicoflagellates, then any additional groups alphabetically, with
"Other" always last.

## Usage

``` r
heatmap_group_levels(groups)
```

## Arguments

- groups:

  Character vector of group names present.

## Value

Character vector of group levels (top-to-bottom display order).
