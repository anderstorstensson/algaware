# Carbon conversion for large diatoms (Menden-Deuer & Lessard 2000)

Mirrors iRfcb's default diatom equation (`diatom_equation = "large"`); a
unit test asserts the two stay identical.

## Usage

``` r
vol2c_diatom_large(volume_um3)
```

## Arguments

- volume_um3:

  Biovolume in cubic microns.

## Value

Carbon in picograms.
