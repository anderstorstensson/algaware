# Shared colour palette for phytoplankton groups

One palette used by both the pie-chart group map and the heatmap group
strips so a group always has the same colour across the report.
`"Ciliates"` (heatmap only) is a darker gold in the same family as the
*Mesodinium* pie colour: the heatmap strip label is text on a light grey
band, where the brighter pie yellow lacks contrast.

## Usage

``` r
phyto_group_colors()
```

## Value

Named character vector of hex colours.
